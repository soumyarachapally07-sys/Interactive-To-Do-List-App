Interactive To-Do List App

**Project Title**
**INTERACTIVE TO-DO LIST APP**

**Technologies Used****
- HTML5
- CSS3
- JavaScript
- DOM Manipulation

**Project Description**

This is a simple and interactive To-Do List web application. Users can add tasks, mark tasks as completed, and delete tasks.

**Setup Instructions****
1. Download or clone this repository.
2. Open the project folder.
3. Open the "index.html" file in a web browser.
4. The To-Do List App will start running.
5. Enter a task in the input box and click Add Task.
6. You can mark a task as completed or delete it.

**Project files**

- "index.html" – Creates the structure of the application.
- "style.css" – Adds styling and layout.
- "script.js" – Adds interactive functionality.
- "README.md" – Contains project information and setup instructions.
